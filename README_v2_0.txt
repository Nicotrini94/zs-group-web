# ZS GROUP WEB v2.0 — Contenido institucional

Esta versión fue revisada para mantener el contenido institucional dentro de lo expresado en el brochure oficial de ZS GROUP SRL.

## Cambios principales
- Textos de Sobre Nosotros y Servicios ajustados al brochure.
- Eliminación de estadísticas, promesas y descripciones técnicas no incluidas en el brochure.
- Clientes visibles: Vital, Megatone, Cetrogar, Norauto, Ingesec y Contartese.
- Logos encuadrados y con fondo transparente.
- Portfolio conservado con fotos y videos reales provistos por la empresa.
- Descripciones de obras neutralizadas para no agregar información no aprobada.

## Ejecutar
```powershell
npm install
npm run dev
```

Abrir http://localhost:3000
