ZS GROUP WEB v1.1 - PORTFOLIO PREMIUM

MEJORAS INCLUIDAS
- Lightbox de imágenes en pantalla completa.
- Navegación con flechas y teclado (izquierda/derecha).
- Cierre con tecla Escape.
- Contador de imágenes.
- Ficha técnica por obra.
- Botones de obra anterior y siguiente.
- Texto "Explorar obra" en el portfolio.
- Diseño responsive para celular.

INSTALACIÓN
1. Descomprimir el ZIP.
2. Abrir la carpeta zs-group-web en Visual Studio Code.
3. Ejecutar: npm install
4. Ejecutar: npm run dev
5. Abrir: http://localhost:3000

NOTA SOBRE VIDEOS
Esta versión integra el portfolio fotográfico premium. El ZIP recibido no contenía los videos originales dentro de public/, por eso no se agregaron todavía. Se incorporarán en la siguiente versión cuando se copien los archivos de video al proyecto.
